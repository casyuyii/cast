时不时会遇到有人问你, 什么是 x?

这个问题因人而已, 因问题而已. 没有标准答案. 有 n 个人, 就有 n 种解释. 

(PS: 我这里说的没有标准答案的意思是: 随着个人对这个物品/概念理解的加深. 会得出不同的结论. 或许这些结论无线接近'真理'. 但那本质上是因为比你有更加深入的理解而得出的结论, 那么是否可以假设: 如果有人比他有对此更加深入的理解, 那么那是否是个更好的答案? 而这样的过程是无穷的)

当一种概念诞生时, 总是会拿现有的东西去理解记忆它. 这是一个比较简便的方式. 也就是我们常说的经验. 假设事物 z 诞生时, 它与 x 和 y 很像. 熟悉 x 的人可以通过 x 理解. y 也可以这么做. 

一种情况是 z 是 x 和 y 的纯粹结合体. 这种情况就类似一种语法糖. 但 z 或许带有不同的, 即使是非常微小的差异. 这种情况下 x 和 y 就无法完全解释 z. 需要有一些 emm... 新的概念. 

而这种过程也是无穷的, z 可以在另一种场景下是 x 或 y.

emm... 我想说什么呢? 我觉得自己得有自己的理解, 自己的主见. 即使这些主见不同于主流. 即使这些主见学自于他人. 这个问题与其是在问标准答案. 不如说是在问: 给我说说你对这个概念的理解. 

我曾遇到有人问过这个问题, 我说了我的见解. 他说不对 😅. 然后说了一些他说是可以在网上搜索到的标准答案. 看来他将其当为信条了...

我希望自己能是一个有主见的人. 即使这大多数情况下导致我事倍功半 😂

我希望也可以多方面思考, 为什么有这东西, 这东西如何实现的. 更有趣的是这些背后的故事.
